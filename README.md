# Analysis code for "Pre-movement sensor-level EEG activity recorded with a portable three-channel system is associated with futsal free-kick outcomes"

## Scripts

- `code/00_capture_svm_design.py`: SVM trial order and permutation seeds.
- `code/01_preprocess_eeg.py`: EEG preprocessing.
- `code/02_fooof_exclusion.py`: FOOOF-based trial exclusion.
- `code/03_svm_analysis.py`: within-day and cross-day SVM analyses.
- `code/04_band_power_analysis.py`: alpha- and beta-band power comparisons.
- `code/05_behavior_summary.py`: behavioral summaries.
- `code/06_fooof_spectral_summary.py`: FOOOF spectral summaries.
- `code/07_cwt_analysis.py`: continuous wavelet analysis.
